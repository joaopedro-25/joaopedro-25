## Sobre mim

Sou **João Pedro**, estudante de **Análise e Desenvolvimento de Sistemas** e desenvolvedor Full Stack em formação. Tenho experiência prática em projetos de desenvolvimento web e sigo aprofundando meus conhecimentos em **Java, Spring Boot e bancos de dados relacionais**.

- Desenvolvimento de interfaces com **HTML, CSS, JavaScript, React e Next.js**.
- Estudos e projetos de back-end com **Java, Spring Boot e PostgreSQL**.
- Participação no **SP Spaces**, plataforma de aluguel de espaços comerciais do Grupo São Paulo.
- Atuação na **Seeds Tecnologia**, conectando aprendizado, trabalho em equipe e projetos práticos.
